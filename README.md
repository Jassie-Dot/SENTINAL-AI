# 🛡️ SENTINAL AI

SENTINAL AI (Self-Evolving Neural Technology for Intelligent Networked Autonomous Learning) is an AI-powered desktop assistant designed to analyze activity, understand user intent, and assist with intelligent automation.

It is built using **Node.js, Electron, and modular AI engines** that allow the system to learn from interactions, maintain memory, and evolve over time.

---

## 🚀 Features

- 🧠 Intelligent AI conversation engine  
- 💾 Short-term and long-term memory system  
- ❤️ Emotion and empathy modules  
- 🌐 Internet intelligence for knowledge retrieval  
- 🖥️ System interaction tools  
- 🔌 Plugin architecture for extending capabilities  
- 🧬 Self-evolution engine for adaptive learning

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Jassie-Dot/SENTINAL-AI.git
cd SENTINAL-AI
```

Install dependencies:

```bash
npm install
```

Start the AI:

```bash
npm start
```

---

## 🛠️ Development

Run the project in development mode:

```bash
npm run dev
```
